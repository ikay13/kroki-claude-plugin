# D2 Reference

D2 is a modern diagramming language with clean syntax, automatic layout, and built-in theming. Good for architecture diagrams, system designs, and anything with labeled relationships.

**Engine:** Core gateway (no companion container needed)
**File extensions:** `.d2`
**Kroki type string:** `d2`

## Basic Diagram

```d2
server: API Server {
  shape: rectangle
}
db: PostgreSQL {
  shape: cylinder
}
client: Browser

client -> server: HTTPS
server -> db: SQL
```

## Nested Containers

```d2
cloud: AWS {
  vpc: VPC {
    web: Web Tier {
      lb: Load Balancer
      app: App Server
      lb -> app
    }
    data: Data Tier {
      db: RDS
      cache: ElastiCache
    }
  }
}
cloud.vpc.web.app -> cloud.vpc.data.db
cloud.vpc.web.app -> cloud.vpc.data.cache
```

## Sequence Diagram

```d2
shape: sequence_diagram
alice: Alice
bob: Bob
alice -> bob: "Authentication Request"
bob -> alice: "Authentication Response"
```

## Legend Support

**Native.** D2 supports positioned containers:

```d2
legend: Legend {
  near: top-right
  blue: "Core subsystem"
  gray: "External system"
}
```

## Common Pitfalls

- Colons in labels must be quoted: `node: "Label: with colon"` not `node: Label: with colon`
- `shape: sequence_diagram` is a top-level directive, not per-node
- Nested references use dot notation: `parent.child -> other.child`
- D2 auto-layouts — manual positioning is limited by design
