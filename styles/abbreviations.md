# Abbreviations

Acronyms used across engineering diagrams. Added to the legend when the
corresponding acronym appears in diagram body text.

## Canonical YAML

`styles/abbreviations.yml`

## Extending

Add new entries in alphabetical order. Keep expansions terse (the legend has
limited horizontal space). If a term is domain-specific to a single diagram,
prefer an inline note over adding it here.

## Categories

Abbreviations are not categorized in the YAML (flat map). The `render-with-legend.sh`
tool filters to abbreviations that actually appear in the diagram source, so
redundant entries do not bloat the legend.
