# Naming Prefixes

SE/SW/PM-aligned prefixes for diagram filenames. This list is expandable — add new prefixes as needed.

## Systems Engineering

| Prefix | Meaning |
|--------|---------|
| `ctx-` | Context view (C4 Level 1) |
| `cont-` | Container view (C4 Level 2) |
| `comp-` | Component view (C4 Level 3) |
| `code-` | Code view (C4 Level 4) |
| `arch-` | High-level architecture (non-C4) |
| `bd-` / `ibd-` | SysML Block / Internal Block Diagram |
| `act-` | Activity diagram |
| `state-` | State machine |
| `seq-` | Sequence diagram |
| `use-` | Use case diagram |
| `req-` | Requirement diagram |
| `ver-` / `val-` | Verification / Validation flow |

## Software Engineering

| Prefix | Meaning |
|--------|---------|
| `dfd-` / `cfd-` | Data Flow / Control Flow Diagram |
| `class-` / `obj-` | Class / Object diagram |
| `erd-` / `schema-` | Entity-Relationship / Database schema |
| `deploy-` | Deployment topology |
| `net-` / `rack-` / `pkt-` | Network / Rack / Packet layout |
| `wave-` | Timing / waveform diagram |
| `vhdl-` | VHDL entity symbol |
